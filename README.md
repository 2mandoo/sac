# Concert Info & Booking Assistant 🎵
Open API를 활용하여 연주회 정보와 예매 데이터를 시각화하여 예매 의사결정을 돕는 웹페이지입니다.

또한, 네이버 캘린더 API를 연동하여 관심 있는 연주회를 캘린더에 쉽게 저장할 수 있습니다

#### 주요 기능 ✨
- 연주회 정보 조회

  Open API를 통해 최신 연주회 정보를 받아옵니다.

  연주회 이름, 날짜, 장소 등의 정보를 사용자에게 제공합니다.

- 나이대별 예매 정보 시각화

  나이대별 예매 데이터를 가져와 그래프로 시각화하여 사용자에게 보여줍니다.
  
  데이터를 기반으로 연주회 선택에 도움을 줍니다.

- 캘린더 연동

  네이버 캘린더 API를 연동하여 연주회 정보를 클릭 한 번으로 캘린더에 추가할 수 있습니다.

  연주회 일정이 자동으로 저장되어 관리가 편리해집니다.

- 빛의 인터랙션 효과

  연주회 포스터에 마우스를 올리면 마우스 위치를 따라 조명이 움직이며, 포스터가 동적으로 반응합니다.
 
  애니메이션 효과로 사용자의 흥미를 유발하며 감각적인 경험을 제공합니다.
